# Контрольный час (11:00, время Астаны) — команды по порядку

Открыть PowerShell в папке `SapaRate`. `<group_id>` — значение, которое назовут организаторы.

```powershell
git pull --rebase
python scripts/control_run.py <group_id>
python scripts/validate_results.py results/prod/results.json --expect-count 10
git add results/prod/results.json
git commit -m "Control set results"
git pull --rebase
git push
```

`control_run.py` сам: скачает набор из API → оценит все диалоги параллельно (4 потока) → повторит упавшие →
запишет `results/prod/results.json` → запустит проверку (ровно 10 записей) → напечатает ok / error / время. **Push он не делает.**

Если в конце пишет `✓ Проверка формата пройдена` — можно делать commit и push. Если `✗` — прочитайте список проблем.

## Если что-то пошло не так
- **API не отвечает:** сохраните ответ организаторов в файл `control.json` (вне git) и запустите
  `python scripts/control_run.py <group_id> --file control.json`.
- **Часть диалогов в error:** запустите команду ещё раз — уже оценённые пропустятся, оценятся только упавшие
  (`ok`-диалоги второй раз не тратят запросы). Запись `error` в файле — это нормально и честно, лучше, чем нулевая оценка.
- **Лимит модели:** бесплатный Gemini даёт **20 запросов в день на каждую модель**. В `GEMINI_MODEL` (по умолчанию) стоит цепочка из
  4 моделей — когда у одной кончается дневной лимит, система сама берёт следующую. Сброс лимитов — в 13:00 по Астане, то есть
  **после** контрольного часа, поэтому не тратьте запросы на лишние прогоны. Модели `gemini-3.5/3.6-flash` сегодня уже исчерпаны,
  `gemini-3.7/3.8-flash` отвечают по 100+ секунд — они в цепочку не входят.
- **Проверить, что модель отвечает, до 11:00:** не нужно, каждый тест тратит запросы. Страница `http://127.0.0.1:8000/api/health`
  (после `python run.py`) показывает цепочку моделей.
- **Конфликт при `git pull --rebase`:** `git rebase --abort`, ничего не форсировать, позвать человека.
- Параметры: `--workers 4` (одновременно), `--retries 2` (повторов упавших), `--model "a,b"` (другая цепочка моделей).

## Замена критерия в этот же час
Если организаторы попросят заменить критерий: см. `docs/criterion_change.md`, затем снова
`python scripts/control_run.py <group_id> --fresh` (оценит все 10 заново новой версией чек-листа; расходует ещё 10 запросов)
и те же проверка + commit + push. Выгрузка берёт самую свежую оценку каждого диалога.

## Ключи (обновлено)
- В `.env`: `GEMINI_API_KEYS` (12 ключей) и `GEMINI_KEY_LABELS` (названия 06…11, 00…05). Лимит общий внутри Google-аккаунта: 00–05 — один аккаунт (preview на сегодня исчерпана), 06+07, 08+09, 10+11 — по аккаунту.
- Модель по умолчанию: `gemini-3-flash-preview`, затем `gemini-3.5-flash-lite` (много запросов в день, 15 в минуту на аккаунт), затем остальные lite.
- Ограничить прогон ключами: `python scripts/control_run.py <group_id> --keys 08,09,10,11`. Без `--keys` берутся все 12 по порядку; исчерпанные ключи пропускаются сразу (без ожидания).
